Toadstone vs Screaming Frog, honestly

A side-by-side from public pages, with what Toadstone doesn't do yet and where Screaming Frog is the better pick. We make Toadstone, so check our sources.

Read this first. We make Toadstone, so we have an interest in how this comes out. To limit that: each claim below points at a public page, either Toadstone's own repo or Screaming Frog's own pages, read on 2026-10-24. Where we couldn't confirm something about Screaming Frog we say so rather than guess. We are not affiliated with Screaming Frog, we did not ask them to review this, and "Screaming Frog" is their name and mark. If we got something wrong, open an issue and we will correct it.

What Toadstone doesn't do (yet)

If one of these is a requirement for you, Toadstone is the wrong choice today. Some are gaps we may close; the keyword and rank items are deliberate.

  • Per-client projects or workspaces. Toadstone has no project or client folder concept. Agencies running many clients will have to separate them by hand.
  • PDF reports. Not supported. It produces HTML and Markdown reports and data exports, not PDFs.
  • White-label reports. Not supported. You cannot put your own branding on its output.
  • Keyword research. Not included, and not planned. It is a crawler, not a keyword tool.
  • Rank tracking. Not included, and not planned.
  • A backlink index. It has none of its own. It can read domain authority and link counts if you bring a Moz, Majestic or Ahrefs key.
  • Crawling millions of URLs. Not what it is for. It stores page bodies and is built for tens of thousands of pages on ordinary hardware.
  • Importing a list of URLs from a CSV. Wanted, not started. Screaming Frog has a list mode.
  • Continuous monitoring. Crawls run on a schedule. There is no always-on watcher or sub-minute alerting.
  • A support contract or guaranteed answers. None. There is no phone line, no SLA and no paid tier.
  • A native desktop installer. You need Docker, or Python 3.11+ plus Chromium. Someone has to be comfortable running that.

Source: Toadstone's own README and roadmap[T1].

When Screaming Frog is the better pick

  • You want a desktop app with a licence and support behind it[S1][S2]. Toadstone's own README says as much.
  • You crawl very large sites. Screaming Frog is built for millions of URLs[S2]; Toadstone is not[T1].
  • You run many clients and need to keep their crawls in separate project folders[S2].
  • You want the deeper AI-assistant integration: more tools and bulk exports[S3].
  • You value a mature, widely used tool with long documentation history.

When Toadstone may fit better

  • Your team is large and per-seat licence cost matters. Toadstone has no seat fees; run the numbers.
  • You want a crawl to gate a deploy: --fail-on error returns a non-zero exit code[T1].
  • You want your crawl data to stay on your own machine, read by your own AI assistant through a read-only MCP server[T2].
  • Your sites are in the thousands or tens of thousands of pages, and you don't want a licence fee for them.
