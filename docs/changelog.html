Known issues

From issue #1 on GitHub, opened 23 Oct 2026 while crawling the ten study sites, and still open when we checked on 24 Oct 2026. We have not re-tested each item today. Until they are fixed, treat a "broken" finding on a site you do not control as a lead, not a verdict, and check it with curl.

False positives

  • Bot walls counted as broken.

    The image and broken-link checks treat 401 and 403 responses (a site refusing a bot) as broken. On Moz this produced a false "301 pages link to broken URLs". Suggested fix: broken means 404, 410 or 5xx; report 401 and 403 separately as "blocked, unverified".

  • Cloudflare image URLs with commas are truncated.

    URLs such as /cdn-cgi/image/width=…,quality=…/ are cut at the comma, giving a fake broken image (seen on Yoast).

  • robots.txt behind a Cloudflare challenge reads as disallow-all.

    That then flags canonicals the crawler cannot verify.

  • 1×1 tracking pixels flagged for missing alt text.
  • The modified-date check is noisy behind CDNs.

Crawl limits and politeness

  • The command line has no flags for max URLs, user agent or delay.

    Max URLs defaults to 5,000,000 on the CLI. The web app has these settings, and the MCP server enforces its own 2,000-URL cap.

  • Sitemap fetches and image checks ignore the delay setting.

    A 300-page crawl made about 3,000 requests on image-heavy sites. The study's crawl settings and filters are described on the method page.

The public demo page

  • Missing metadata on the GitHub Pages demo.

    Issue #1 notes that the demo at spcaeo.github.io/toadstone had no meta description, canonical, OG or Twitter tags, structured data or sitemap. The only related change we can see in the history is the web UI template line on 23 Oct; the issue is not marked resolved.

From the project's own changelog

  • One front-end file is far over the project's own size rule.

    web/static/js/app.js is 4,548 lines against a 1,000-line rule. Listed as debt, not exempted.

  • A race between the two crawl loops.

    A URL discovered just as the pool shuts down can be submitted after shutdown and lost. Recorded as open, not fixed.

  • Some checks are proven only against stubbed data.

    gsc_canonical_overridden and the paid link-metrics checks are tested against stubbed transports. The repo's BUILD-LOG.md says what that does and does not establish.

Not built

Things people ask for that Toadstone does not do today. We are not promising any of them.

  • Per-client projects or workspaces
  • PDF reports and white-label output (exports are Excel, CSV, HTML and Markdown)
  • Keyword research
  • Rank tracking

See the sourced comparison page for where Screaming Frog is the better choice. To report a problem or suggest something, open an issue on GitHub.
