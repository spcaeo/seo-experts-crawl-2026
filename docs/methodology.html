How we crawled 10 SEO sites, and what we did and didn't count

Short version: polite crawls, conservative rules, every exclusion shown. Back to the results or read the FAQ.

The crawl

  • Tool: Toadstone, our own crawler (free, self-hosted, source-available under the Elastic License 2.0). Because we built it, we publish every rule so you can check our work.
  • Date: 23 Oct 2026, roughly 18:50–19:27 ET. Examples re-verified with curl 19:45–19:48 ET.
  • Limits: up to 300 URLs per site or 25 minutes, whichever came first (four sites hit the time cap, which is why a few have fewer than 300 pages), depth 5, 0.5 s delay, concurrency 2, and a hard global cap of 2 requests per second (including image checks and robots.txt). Sitemaps were not fetched.
  • robots.txt respected; no logins; no cookies kept.
  • User agent: ToadstoneBot/1.0 (+https://github.com/spcaeo/toadstone; polite research crawl, <=2 req/s)
  • Start points: each site's blog or learn hub, or the homepage where there is no hub (see commands below). Scope is the first ~300 URLs the crawler reached, which is a sample, not a census.

What counts as an issue

  • Page checks only apply to HTML pages that returned HTTP 200.
  • No meta description, no canonical, no H1, more than one H1: per page.
  • Content image without alt: a page counts once if it has at least one non-decorative image (not a 1×1 pixel or tracker) with no alt attribute. An empty alt (alt="") is valid for decorative images and is not flagged.
  • Broken URL: an internal URL returning 404, 410 or any 5xx.
  • Linked URL redirects: an internal URL that returns a 3xx and is linked from another crawled page.
  • Counted issues = the sum of those seven columns. See the data dictionary.

What we deliberately did not count

  • 401, 403, 429 and no-response URLs (177 in total): bot walls, not errors.
  • Titles over 60 characters, near-duplicate pages, cross-domain canonicals: informational columns only.
  • Flags Toadstone raised that we replaced with a stricter recount or judged to be false positives. Every one is below and in excluded-flags.csv.

Reproduce it

You need a local Toadstone checkout and Python. Run each crawl (about 5–25 minutes each at 2 requests/second), then build the data and charts from the raw JSON. The raw JSON includes page text, so we do not publish it; the cleaned data is in the repo.

python scripts/ts_crawl.py https://www.semrush.com/blog/ raw/semrush.com.json --max 300 --delay 0.5 --concurrency 2 --rps 2 --depth 5 --timeout 1500 --include '^https://www\.semrush\.com/blog'
python scripts/ts_crawl.py https://surfer.ai/blog/ raw/surfer.ai.json --max 300 --delay 0.5 --concurrency 2 --rps 2 --depth 5 --timeout 1500 --include '^https://surfer\.ai/blog'
python scripts/ts_crawl.py https://neilpatel.com/blog/ raw/neilpatel.com.json --max 300 --delay 0.5 --concurrency 2 --rps 2 --depth 5 --timeout 1500 --include '^https://neilpatel\.com/blog'

python scripts/verify_examples.py
python scripts/build_web_data.py && python scripts/make_charts.py && python scripts/build_page.py
